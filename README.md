# BlueNotes

A simple notes application built with React and Tailwind CSS.

## Features

* Create notes
* Delete notes
* Dynamic rendering with React state
* Local storage support
* Responsive layout
* Clean blue-themed interface

## Tech Stack

* React
* JavaScript
* Tailwind CSS
* Vite

## What I Learned

* React useState
* Controlled form inputs
* Event handling
* Array state management
* Rendering lists with map()
* Local storage integration
* Component-based UI development
